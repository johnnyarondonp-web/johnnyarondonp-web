### Sobre Mí

Mi camino en el desarrollo web comenzó cuando descubrí el potencial de modificar y construir interfaces desde cero. Hoy, como **Ingeniero en Informática**, me especializo en la creación de aplicaciones y sistemas web estructurados utilizando Laravel, TypeScript y React, siempre bajo una metodología rigurosa y con atención minuciosa al detalle.

Mi enfoque al programar se basa en dos principios:

*   **Planificación y Estructura:** Considero fundamental definir y entender la arquitectura, los requerimientos del sistema y las reglas de negocio antes de escribir la primera línea de código. La planeación previa es clave para un desarrollo limpio.
*   **Atención al Detalle:** Me enfoco rigurosamente en la robustez lógica y en el manejo de casos de borde (edge cases). Presto especial atención a la validación estricta y sanitización de entradas de datos para asegurar que los sistemas sean seguros y estables.

### Proyectos Destacados

#### 🐾 [Zoion Sistema](https://github.com/johnnyarondonp-web/Zoion-sistema)
*Sistema web de gestión clínica veterinaria enfocado en la automatización de citas y el control operativo.*

*   **Tecnologías:** Laravel 13, Inertia.js, React (TypeScript) y PostgreSQL.
*   **Desarrollo Técnico:**
    *   **Asignación de Citas:** Algoritmo automatizado que distribuye de manera equitativa la carga de consultas diarias entre los doctores disponibles (lógica Round-Robin).
    *   **Integridad de Datos:** Implementación de reglas estrictas de validación única en campos críticos (cédula, teléfono y correo) para prevenir colisiones relacionales entre los distintos roles del sistema.
    *   **Control de Concurrencia:** Uso de bloqueos atómicos temporales para evitar reservas duplicadas en franjas horarias simultáneas.
    *   **Onboarding:** Seeders idempotentes para el catálogo de servicios clínicos y personal de pruebas, permitiendo una inicialización inmediata del proyecto.

#### 📈 [Eunoia Sistema](https://github.com/johnnyarondonp-web/eunoia-sistema)
*Sistema web para la gestión administrativa, ventas y control de inventarios.*

*   **Tecnologías:** Laravel 13, Blade, Tailwind CSS y base de datos relacional indexada.
*   **Desarrollo Técnico:**
    *   **Lógica de Inventario:** Algoritmo integrado para evaluar los costos de inventario bajo el método FIFO (primero en entrar, primero en salir).
    *   **Gestión Multidivisa:** Lógica automatizada para transacciones de venta soportando tasas de cambio variables en tiempo real.
    *   **Optimización:** Estructuración de índices en base de datos para agilizar consultas complejas y la generación de reportes comerciales.
